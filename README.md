# 🌿 Vaibhav Nursery — *Grow your own era*

> **Vaibhav Nursery** is an end-to-end modern plant nursery, organic agriculture platform, and smart gardening companion designed for both urban balcony growers and commercial farmers.

## ✨ Key Features

- 🌱 **Hero Studio & Verdi Mascot**: Interactive intro featuring brand mascot Verdi with real-time wisdom quotes, custom typography (*Chillin on Sunday*), and warm botanical aesthetic.
- 💧 **Interactive Living Sapling Simulator**: Fully animated watering experience with physical gravity-aligned water streams, multi-tier droplet shower, soil ripples, and progressive 4-stage organic growth (🌰 Dormant Seed $\rightarrow$ 🌱 Sapling $\rightarrow$ 🌿 Vegetative $\rightarrow$ 🍅 Lush Flora with ripe fruit).
- 🧭 **14 Branches of Agriculture Knowledge Network**: Interactive mindmap unifying Agronomy, Horticulture, Soil Science, AI Plant Pathology, and Nursery Management.
- 📱 **9-Screen Interactive Mobile App Simulator**: Full high-fidelity mobile prototype including:
  1. Animated Splash Screen
  2. Secure Grower Sign-In
  3. Real-Time Command Dashboard
  4. Plant Care & Watering Reminders
  5. Marketplace Store with verified inputs
  6. AI Leaf Scanner & Doctor
  7. Terrace Garden Layout Builder
  8. Community Forum & Exchange
  9. Seasonal Crop Guide
- 🛍️ **Doorstep Inputs Marketplace**: Custom hand-crafted vector graphics for **Enriched Vermicompost (5kg)** and **350 GSM Breathable Geotextile Grow Bags**, plus tools, bio-boosters, and live saplings with cart & discount drawer.
- 🧮 **Terrace & Balcony Yield Calculator**: Dynamic estimator calculating annual vegetable yield, cost savings (up to ₹30,000/yr), and custom Vaibhav Nursery starter kits.
- 🧪 **Ancient Natural Farming Formulations**: Step-by-step recipes for Jeevamrutha, Neem Astra, and Compost Tea.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with customized botanical earth palette (`#F4F2F2`)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio Engine**: Synthetic Web Audio API synthesizer for tactile clicks, water drop plops, and sprout chimes
- **Typography**: Self-hosted *Chillin on Sunday* and *Plus Jakarta Sans*

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Shalmali1814/vaibhav-nursery.git

# Navigate into project directory
cd vaibhav-nursery

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
